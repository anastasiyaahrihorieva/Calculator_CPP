# Wrapper

Проект реализует инкапсуляцию методов класса произвольной сигнатуры

## Функциональность

- `Wrapper<T>` — обёртка над методом класса, которая позволяет вызывать метод с аргументами, переданными в виде `std::map<std::string, int>`.
- `Engine` — позволяет регистрировать команды по строковому имени и вызывать их из другого модуля, не зная внутренней реализации.
- Поддержка произвольного числа аргументов с использованием variadic templates.
- Поддержка аргументов по умолчанию.
- Вызов методов с аргументами в любом порядке.
- Обработка ошибок: вызов несуществующей команды.

## Структура проекта

- `main.cpp` — точка входа в программу.
- `tests.cpp` — содержит тесты для проверки.
- `wrapper.h` — объявление шаблона `Wrapper` и класса `Subject`.
- `wrapper.cpp` — реализация методов `Subject`.
- `engine.h` — объявление класса `Engine`.
- `engine.cpp` — реализация методов `Engine`.
- `CMakeLists.txt` — файл для сборки проекта с помощью `cmake`.

## Требования

- Компилятор C++ с поддержкой C++17.
- Установленный `cmake` версии 3.10 или выше.

## Сборка и запуск

1. Установлены `g++` и `cmake`.

2. Скачать или клонировать проект.

3. В корне проекта выполните:

```bash
mkdir build
cd build
cmake ..
make
```

4. Запуск исполняемого файла:

```bash 
./app
```
