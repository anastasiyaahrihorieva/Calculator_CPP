# Extensible Console Calculator

## Описание
Данный проект представляет собой расширяемый консольный калькулятор, написанный на языке C++. Программа вычисляет математические выражения в инфиксной нотации, предварительно преобразуя их в обратную польскую запись (Reverse Polish Notation, RPN) с помощью алгоритма сортировочной станции (Shunting-yard algorithm). 

Ключевой архитектурной особенностью проекта является система плагинов, позволяющая подключать новые математические функции динамически (во время выполнения) с использованием библиотек DLL, без необходимости перекомпиляции основного приложения.

## Ключевые возможности
* **Базовая арифметика:** Поддержка стандартных операций (`+`, `-`, `*`, `/`) и скобок для управления приоритетом вычислений.
* **Алгоритмическая база:** Эффективный парсинг выражений на основе RPN.
* **Система плагинов:** Автоматическая загрузка пользовательских функций из `.dll` файлов, расположенных в директории `./plugins`.
* **Безопасность и отказоустойчивость:** Обработка ошибок ввода, проверка деления на ноль и контроль корректности количества операндов.

## Структура проекта
* `main.cpp` — точка входа, инициализация загрузчика плагинов и цикл обработки пользовательского ввода.
* `calc.h` / `calc.cpp` — модуль вычисления математического результата на основе подготовленного RPN-массива токенов.
* `parser.h` / `parser.cpp` — реализация алгоритма Shunting-yard для перевода инфиксного выражения в постфиксное (RPN).
* `dllLoad.h` / `dllLoad.cpp` — класс `DllLoader`, отвечающий за поиск, загрузку и связывание динамических библиотек из файловой системы.
* `supports.h` / `supports.cpp` — вспомогательные утилиты для определения чисел, валидации функций и расчета приоритета операторов.
* `calc.exe` — скомпилированный исполняемый файл приложения.

## Требования
* **ОС:** Windows (приложение использует Windows API `LoadLibraryW`, `GetProcAddress`, `FreeLibrary`).
* **Компилятор:** С поддержкой стандарта C++17 или выше (используется библиотека `<filesystem>`).
